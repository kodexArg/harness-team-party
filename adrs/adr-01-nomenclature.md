# ADR-01 — Nomenclature & Language Standards

> Active nomenclature coherence and clear linguistic boundaries eliminate ambiguity, duplicate model state, and vocabulary drift across code, documentation, and user interfaces.

1. **Active Nomenclature Coherence:** Naming across models, schemas, payload fields, API paths, UI components, configuration tokens, and documentation must maintain consistent semantic concepts.
2. **Model and Entity Hygiene:** Avoid redundant, duplicate, or overlapping fields in models and payload shapes. Every attribute carries a distinct domain concept.
3. **Universal English Codebase:** English is the language for the technical repository: source code, identifiers, database tables and columns, API paths, JSON keys, configurations, tests, commit messages, and technical documentation.
4. **Rendered Interface Language:** Code, docs, and skill text in this repository are English.
