# kskill-qw

`/qw` is `/kdx-mood quick win`. Named after Quick Win. There is no
separate stance here.

## Do this

1. Confirm in one short line: mood `quick-win` is active.
2. Read `skills/kskill-mood/references/quick-win.md` and follow it.
   If `kskill-mood` itself is needed (other moods, combining), read
   that skill too. Do not copy its parser into this file.
3. Execute the given task under that stance.

## Do not

- Invent a second quick-win procedure.
- Skip the understand / PR / merge / cowsay loop when the task is
  repo work.
- Override [[AGENTS]], the ABC gate, or [[INTERFACES]].
