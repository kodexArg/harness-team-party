# Voice — low verbosity (default)

Reports are pointers, not essays.

## Defaults

- One hook line under the title. No trailing filler.
- Sections: kicker + short heading + ≤3 short paragraphs or a tight list.
- Ration `<strong>`: at most one load-bearing phrase per section.
- One `<div class="takeaway">` max — the conclusion only.
- Prefer chips over paragraphs for status.
- Middot `·` for beats; arrow `→` for transformation.
- Lowercase headings; uppercase only on kickers.

## Expand only when asked

If the caller says verbose / largo / completo / full / detailed — raise density.
Otherwise cut. If a sentence does not change a decision, delete it.

## Language

- `gj-sk-report` → English (neutral, terse).
- `gj-sk-reporte` → Castellano (rioplatense when natural: *vos*, *mandá*, *acá*); same terseness.

Do not mix languages inside one artifact unless the source content already does.
